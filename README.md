# Werkplaats — Ouwejan & F. de Bruijn Infra

Dit is jullie eigen werkmap. Alles wat jullie digitale collega's voor jullie
bouwen — scripts, kleine tools, automatiseringen, aanpassingen — komt hier
terecht, en nergens anders.

Het is een git-repo: elke wijziging wordt vastgelegd, dus je kunt altijd
terugkijken wat er veranderd is en zo nodig terug naar een eerdere versie.

**Deze map staat los van het dashboard zelf.** Het dashboard werkt zichzelf bij
via de Bijwerken-knop; die updates raken deze map nooit aan, en wat hier gebouwd
wordt verdwijnt dus niet bij een update.

## Naar GitHub (optioneel)

Standaard blijft alles op deze Mac — dat is genoeg om te kunnen bouwen en om
versies te bewaren. Willen jullie het ook op GitHub hebben (back-up, of
meekijken vanaf een andere plek), dan koppel je er een eigen repo aan:

    git remote add origin <url-van-jullie-eigen-repo>

Op **Instellingen** in het dashboard zie je daarna of de verbinding echt werkt:
of lezen lukt, of schrijven lukt, en zo niet, wat eraan te doen is.
